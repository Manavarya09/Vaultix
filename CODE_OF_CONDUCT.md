# Code of Conduct

This project follows a standard Code of Conduct to foster an open and welcoming community.

Standards

- Be respectful and considerate in all communications.
- Refrain from harassment, discrimination, or abusive language.
- Be constructive when giving feedback.

Enforcement

Maintainers may remove or edit comments, or block accounts if behavior violates this Code of Conduct.

Reporting

If you experience or witness unacceptable behavior, please contact the maintainers at maintainers@example.com.
